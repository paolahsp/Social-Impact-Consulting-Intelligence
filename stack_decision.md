# Stack Decision

The primary stack for the Project 3 MVP is n8n. Visual orchestration fits the multi-tool research, evidence, RAG, analysis, transformation, and QA workflow. The MVP has integration-heavy API and research branches, and n8n sub-workflows allow Paola and Gretel to configure modules independently. n8n also makes error handling and execution paths visible for the demo and easier to inspect during parallel configuration. LangGraph may be evaluated later for more complex reasoning and stateful evaluation, but it is not the primary stack for this MVP.
